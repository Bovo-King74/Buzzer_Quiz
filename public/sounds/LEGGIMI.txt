SUONI PERSONALIZZATI
====================
Metti qui i tuoi file audio, chiamandoli ESATTAMENTE così
(formati accettati: .mp3  .wav  .ogg  .m4a  .aac):

  buzzer.mp3      ->  suona sull'host quando un gruppo preme il buzzer
  giusto.mp3      ->  suona quando clicchi "Giusta"
  sbagliato.mp3   ->  suona quando clicchi "Sbagliata"

Non serve riavviare il server: basta ricaricare la pagina host.
Se un file manca, il browser usa un semplice bip al suo posto.
Consiglio: file brevi (1-3 secondi) e non troppo pesanti.
